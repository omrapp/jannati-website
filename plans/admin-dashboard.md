## Admin Dashboard Management 

***Goal*** is to refine the Admin Dashboard management UI and permissions and to make it more facial and easy for using with full admin controller and to align to the ree-nextjs-admin-dashboard  


### Tasks

- Use @free-nextjs-admin-dashboard-main directory as reference 

- Build and Align the Admin pages to the free-nextjs-admin-dashboard style and design 

- Add pages like Statistics, Analytic, E-commerce pages (bills, invoices etc...)

- Add ability Admin user can delete multi products or all products or products that only belong to the same categories, or user can delete categories, brands etc ...

- Make sure to make easy to control the website and the contents 

- Add live preview if that possible  once change content or add new products before publishing 

- Add ability Admin user can delete, update or block customers 

- Add Charts and dynamic animation and motions numbers.

- Separate the Admin pages to categories

- Add and implements all the  notification box logic and UI 

- Support Dark and Light theme  

- Support full Arabic and RTL the Admin Dashboard Management  


### Rules

- Don't change no related code, Only work on the relevant code and files

- Don't consume tokens for heavy tasks, let do it manually.

- Spawn tasks to sub-agents for better best practices and performance.

- Always AskUserQuestions to clarify tasks.
